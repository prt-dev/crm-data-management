Mermaid Diagram:

```mermaid
flowchart TD

    CheckPublic -->|"Yes"| RenderAuth["Render Auth Page (/signin, /signup)"]

    RenderApp --> CacheCheck{"📦 In-Memory Cache Available?"}
    CacheCheck -->|"Cache Hit"| HydrateUI["Instant UI Render from Memory Cache"]
    CacheCheck -->|"Cache Miss"| FetchStorage["Load from LocalStorage / Network API"]

    SetCache --> HydrateUI

    HydrateUI --> Subscribe["📡 Subscribe to Live Event Observer<br/>(service.subscribe(callback))"]
    
    Subscribe --> MutateEvent{"🔄 Data Mutated Anywhere?"}
    MutateEvent -->|"Yes (Create / Update / Delete)"| Notify["📢 Trigger notifySubscribers()"]
    Notify --> ReRender["⚡ Reactive Re-Render (0 Page Reload)"]
    
    Subscribe --> Unmount(["🚪 Component Unmounts"])
    Unmount --> CleanSub["🧹 Execute unsub() Cleanup"]
```

2. AUTH & TOKEN LIFECYCLE FLOW
================================================================================

ASCII Diagram:
-------------
[ User Submits Credentials ] ──> [ Validate Input ] ──> [ Token Generated ]
                                                               |
                                                               v
                                                    [ Save in localStorage / Cookie ]
                                                    [ Key: 'nleta_auth_token'       ]
                                                    [ Key: 'nleta_user_profile'     ]
                                                               |
                                                               v
                                                    [ Set Global Auth State ]
                                                               |
                                                               v
                                                    [ Redirect to /dashboard ]

Mermaid Diagram:
----------------
```mermaid
sequenceDiagram
    autonumber
    actor User as 👤 User / Developer
    participant View as 🖥️ Auth Form (/signin)
    participant AuthSvc as 🔐 AuthService
    participant Storage as 💾 localStorage / Cookie
    participant Router as 🧭 Next.js Router

    User->>View: Enters Email & Password
    View->>AuthSvc: login(credentials)
    
    alt Invalid Credentials
        AuthSvc-->>View: ❌ Return Error (Invalid password/email)
        View-->>User: Display Inline Error Toast
    else Valid Credentials
        AuthSvc->>AuthSvc: Generate JWT / Session Token
        AuthSvc->>Storage: setItem('nleta_auth_token', token)
        AuthSvc->>Storage: setItem('nleta_user_session', userObject)
        AuthSvc->>AuthSvc: Set reactive isUserAuthenticated = true
        AuthSvc-->>View: ✅ Return Success (User details + Token)
        View->>Router: router.push('/dashboard' or redirectUrl)
        Router-->>User: Render Dashboard Protected Screen
    end

    Note over User,Router: 🚪 LOGOUT FLOW
    User->>View: Clicks "Sign Out"
    View->>AuthSvc: logout()
    AuthSvc->>Storage: removeItem('nleta_auth_token')
    AuthSvc->>Storage: removeItem('nleta_user_session')
    AuthSvc->>AuthSvc: Clear in-memory active cache
    AuthSvc->>Router: router.push('/signin')
    Router-->>User: Render Clean Sign-in Page
```

                  |                               |
          (Token Exists)                   (Token Null/Empty)
                  |                               |
                  v                               v
    +---------------------------+   +---------------------------+
    | Check Route Destination   |   | Check Route Destination   |
    | - If /signin or /signup:  |   | - If Protected Route:     |
    |   Redirect ➔ /dashboard   |   |   Redirect ➔ /signin      |
    | - If Protected Route:     |   | - If Public Auth Route:   |
    |   Allow Access ✅         |   |   Allow Access ✅         |
    +---------------------------+   +---------------------------+

Mermaid Diagram:
----------------
```mermaid
flowchart TD
    NavStart([User Hits Route: e.g. /leads/create]) --> GetToken["Read Token: localStorage.getItem('nleta_auth_token')"]

    GetToken --> HasToken{"Is Token Present & Valid?"}

    %% USER IS LOGGED IN
    HasToken -->|"YES (Logged In)"| IsAuthRoute{"Is Route /signin or /signup?"}
    IsAuthRoute -->|"Yes"| DashRedirect["Redirect to /dashboard<br/>(User already authenticated)"]
    IsAuthRoute -->|"No"| RoleCheck{"Check Role Permissions<br/>(Admin / Sales / Inspector / HR)"}
    RoleCheck -->|"Authorized"| RenderProtected["✅ Render Target Page with Data"]
    RoleCheck -->|"Unauthorized Role"| RenderForbidden["⛔ 403 Forbidden / Not Found"]

    %% USER IS NOT LOGGED IN
    HasToken -->|"NO (Guest)"| IsPublic{"Is Route Public?<br/>(/signin, /signup, /login)"}
    IsPublic -->|"Yes"| RenderAuthPage["✅ Render Sign In / Sign Up Form"]
    IsPublic -->|"No (Trying to access protected)"| SaveIntended["Save Intended URL: ?redirect=/leads/create"]
    SaveIntended --> RedirectLogin["Redirect ➔ /signin"]
```

            +---------------+---------------+
            |                               |
      (Cache Hit)                     (Cache Miss)
            |                               |

Mermaid Diagram:
----------------
```mermaid
flowchart TD
    Mount([Component Mounts in React]) --> CallSvc["Call Service: e.g. leadService.getAllLeads()"]

    CallSvc --> CheckRAM{"1. Check In-Memory Array (RAM)"}

    CheckRAM -->|"RAM Hit (Fastest)"| ReturnRAM["⚡ Return in-memory data (0ms latency)"]

    CheckRAM -->|"RAM Miss (Empty)"| CheckStorage{"2. Check Persistent LocalStorage"}

    CheckStorage -->|"Storage Hit"| ParseJSON["Parse JSON from Storage Key"]
    ParseJSON --> PopulateRAM["Populate In-Memory Array in RAM"]
    PopulateRAM --> ReturnRAM

    CheckStorage -->|"Storage Empty"| LoadMock["3. Load Initial Mock Dataset (Bootstrap)"]
    LoadMock --> SaveStorage["Save Initial Dataset to LocalStorage"]
    SaveStorage --> PopulateRAM

    ReturnRAM --> SetState["Component sets state: setLeads(data)"]
    SetState --> SubscribeEvent["4. Subscribe: service.subscribe(loadData)"]
    SubscribeEvent --> RenderComplete([✅ Complete UI Hydrated])
```

```mermaid
sequenceDiagram

    Service->>Service: Push to in-memory cache array
    Service->>Storage: setItem('nleta_leads_data', JSON.stringify(leads))
    
    Service->>Service: notifySubscribers()

        Service-->>CompB: 📢 Callback Triggered ➔ loadLiveStats()
```

6. DATA MUTATION & CACHE INVALIDATION LIFECYCLE (CRUD)
================================================================================

Mermaid State Diagram:
----------------------
```mermaid
stateDiagram-v2
    [*] --> IdleState: Cache Hydrated in Memory

    state "Mutation Operation (Create / Update / Delete)" as Mutate {
        IdleState --> ValidateInput: User Submits Mutation
        ValidateInput --> OptimisticUpdate: Valid Payload Confirmed
        OptimisticUpdate --> UpdateMemoryCache: In-Memory Array Updated
        UpdateMemoryCache --> SyncLocalStorage: Persistent Storage Synced
    }

    state "Event Notification & Invalidation" as Invalidate {
        SyncLocalStorage --> NotifySubscribers: Trigger all registered callbacks
        NotifySubscribers --> RecomputeDerivedStats: Recalculate KPIs & Totals
        RecomputeDerivedStats --> RefreshUI: All subscribed components re-render
    }

    RefreshUI --> IdleState: Idle with Fresh Data

    OptimisticUpdate --> Rollback: Storage Failure / Error
    Rollback --> ShowError: Display Error Alert to User
    ShowError --> IdleState: Revert to previous valid state
```

7. LOGGED-IN VS LOGGED-OUT DECISION & ACTION MATRIX
================================================================================

+-----------------------+-----------------------------+-----------------------------+
| Action / State        | When User is LOGGED IN      | When User is LOGGED OUT     |
+-----------------------+-----------------------------+-----------------------------+
| Access /signin        | Redirects to /dashboard     | Shows Sign In Form          |
| Access /signup        | Redirects to /dashboard     | Shows Sign Up Form          |
| Access /dashboard     | Renders Dashboard with Data | Redirects to /signin        |
| Access /leads         | Renders Leads Pipeline      | Redirects to /signin        |
| Access /bde           | Renders Sales Rep Directory | Redirects to /signin        |
| Access /technicians   | Renders Inspectors Roster   | Redirects to /signin        |
| Access /employees     | Renders Staff Directory     | Redirects to /signin        |
| Token Storage         | 'nleta_auth_token' exists   | Token is null or deleted    |
| In-Memory Cache       | Active & Populated in RAM   | Cleared on logout           |
| Observer Listeners    | Subscriptions active        | Cleaned up on route unmount |
| Data Writes (CRUD)    | Allowed & Persisted         | Blocked with Auth Error     |
+-----------------------+-----------------------------+-----------------------------+
