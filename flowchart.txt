```mermaid
    LoadAsset --> InspectChecklist["Conduct Physical & Mechanical Tests:<br/>• Speed Governors & Emergency Brakes<br/>• Traction Ropes & Hydraulic Valves<br/>• Door Interlocks & Sensor Safeties"]
    
    InspectChecklist --> EvalResult{"Safety Criteria Met?"}
    
    EvalResult -->|"No (Defects Found)"| FlagDefect["Log Safety Deficiencies & Violations"]
    FlagDefect --> IssueRectification["Issue Defect Rectification Notice to Client"]
    IssueRectification --> ReAudit["Schedule Re-Inspection"]

    EvalResult -->|"Yes (100% Compliant)"| SafetyRating["Award Safety Score (e.g. 98.8% / 5.0★)"]
    SafetyRating --> CertifyAsset["Issue Official BIS / ISO Safety Compliance Certificate"]
    CertifyAsset --> UpdateRecords["Increment Completed Audits Count (/technicians/[id])"]
```

7. MASTER END-TO-END OPERATIONAL LIFECYCLE & STATE MACHINE
================================================================================

Mermaid State Diagram:
----------------------
```mermaid
stateDiagram-v2
    [*] --> NewInquiry: Client Inbound Inquiry Created
    
    state "1. Sales & Commercial Phase" as SalesPhase {
        NewInquiry --> AuditScheduled: BDE Contacts & Schedules Site Inspection
        AuditScheduled --> UnderReview: Technical Scope Evaluated
        UnderReview --> QuotationSent: Proposal & Commercial Pricing Sent
        QuotationSent --> WonDeal: Deal Won & Contract Signed
    }

    state "2. Client & Asset Onboarding" as OnboardPhase {
        WonDeal --> ClientCreated: Company Profile Created (/clients)
        ClientCreated --> AssetsRegistered: Lifts & Escalators Logged (/client-assets)
        AssetsRegistered --> InspectorAssigned: Safety Inspector Allocated (/technicians)
    }

    state "3. Field Safety Inspection" as AuditPhase {
        InspectorAssigned --> InTransit: Inspector Dispatched
        InTransit --> OnSiteTesting: Shaft, Cab & Motor Testing
        OnSiteTesting --> DefectFound: Safety Violations Detected
        DefectFound --> OnSiteTesting: Rectification Complete
        OnSiteTesting --> Certified: 100% Standards Met
    }

    state "4. Operational Monitoring" as OpsPhase {
        Certified --> ActiveOperation: Certificate Issued (BIS/ISO Compliant)
        ActiveOperation --> DueForAudit: Next Annual Audit Window Approaching
        DueForAudit --> InTransit: Recurring Audit Dispatched
    }

    Certified --> [*]
```
