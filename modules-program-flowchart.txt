         MODULE-BY-MODULE PROGRAM FLOWCHART & LOGICAL EXECUTION FLOW
================================================================================

FLOWCHART SYMBOLOGY & LOGICAL SHAPES GUIDE:
-------------------------------------------
  ( [START / END] )   : Terminator (Oval / Capsule) - Mount / Unmount / Action Start
  [  PROCESS / EXEC ] : Rectangle (Square / Box)   - State updates, UI rendering, calculations
  {   DECISION / IF } : Rhombus (Diamond)          - Condition checks, validation, cache hit/miss
  [/ INPUT / OUTPUT /]: Parallelogram              - User inputs, form submit, toast, URL params
  [[   SUBROUTINE   ]]: Double-Border Box          - Service calls, API fetch, background handlers
  [( DATABASE / STORE)]: Cylinder                  - LocalStorage, In-memory cache, Observer state
